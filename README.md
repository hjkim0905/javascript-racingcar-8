# javascript-racingcar-precourse

## 과제2 - <🏁 자동차 경주 🏎️> 기능 구현 목록

### 입력 처리

- [x] 사용자로부터 자동차 이름 입력받기 (`Console.readLineAsync()` 사용)
  - [x] `"경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)\n"` 메시지 출력
  - [x] `"시도할 횟수는 몇 회인가요?\n"` 메시지 출력

### 구분자 처리

- [x] 구분자(쉼표)를 기준으로 자동차 이름 분리

### 결과(전진 / 멈춤) 계산

- [ ] 각 회차마다 각 자동차에 한 개의 정수 부여 (`pickNumberInRange(0,9)` 사용)
- [ ] 정수가 `4 이상`이면 한 칸 전진, `4 미만`이면 멈춤
- [ ] 최종 회차가 끝난 후 `각 자동차의 전체 전진 횟수를 비교`
  - [ ] `제일 많은 전진 횟수`를 가진 자동차가 우승/공동우승

### 예외 처리

- [ ] Error 발생 시 `process.exit()`을 호출하지 않고 `[ERROR]` 메시지와 함께 Error throw
- [ ] 자동차 이름
  - [ ] 빈 문자열 입력 시
  - [ ] 5자 초과 입력 시
  - [ ] 특수문자 입력 시 (사람 이름이 아닌 `자동차의 이름`이기에 알파벳과 숫자까진 가능)
- [ ] 시도 횟수
  - [ ] 숫자가 아닌 값 입력 시
  - [ ] 정수가 아닌 값 입력 시
  - [ ] 0 이하인 값 입력 시

### 출력

- [ ] 계산 결과 출력 (`Console.print()` 사용)
- [ ] 결과 형식 맞추기 (`차수별 실행 결과` + `단독 우승자 안내 문구` 또는 `공동 우승자 안내 문구 (쉼표로 구분)`)
  - [ ] 각 차수별 결과 출력 (입력 받은 순서대로)
  - [ ] 단독/ 공동 우승자 안내 문구 (공동 우승자의 경우 `쉼표`를 이용하여 구분)
